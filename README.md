# LulaCoin

**LulaCoin** é um protótipo de criptomoeda desenvolvido para demonstrar conceitos fundamentais de blockchain, incluindo transações, mineração e validação em uma rede distribuída. O projeto inclui uma interface web para simulação de transações.

## 📌 Funcionalidades

- Implementação de uma blockchain simplificada com suporte a transações.
- Simulação de mineração e validação de blocos.
- Interface web para interação com a rede e visualização de transações.
- Estrutura modular com separação clara entre backend e frontend.

## 🛠️ Tecnologias Utilizadas

- **Backend**: Python
- **Frontend**: JavaScript, HTML, CSS
- **Banco de Dados**: Arquivos locais para simulação
- **Outros**: Estrutura MVC para organização do código

## 🚀 Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/JcDev-124/LulaCoin.git
   cd LulaCoin
   ```

2. Instale as dependências necessárias (se houver):

   ```bash
   pip install -r requirements.txt
   ```

3. Execute o aplicativo:

   ```bash
   python main.py
   ```

4. Acesse a interface web no navegador:

   ```
   http://localhost:5000
   ```

## 📂 Estrutura do Projeto

- `controller/`: Lógica de controle das rotas e requisições.
- `database/`: Configurações e arquivos relacionados ao armazenamento de dados.
- `domain/`: Definições das entidades e regras de negócio.
- `front-end/`: Arquivos da interface do usuário (HTML, CSS, JS).
- `repository/`: Interações com o banco de dados ou arquivos de dados.
- `services/`: Serviços auxiliares e lógica de negócio adicional.
- `main.py`: Ponto de entrada da aplicação.
- `README.md`: Documentação do projeto.
